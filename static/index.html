ANTES DE EMPEZAR

Te ayudamos a preparar tu trámite consular para que llegues sabiendo qué necesitas, qué tienes, qué te falta y qué debes confirmar.

¿PARA QUIÉN ES?

Para mexicanos que viven en Estados Unidos: niños, jóvenes y adultos.

¿CÓMO FUNCIONA?

Primero identificamos tus datos. Después eliges el trámite. Luego revisamos los requisitos contigo, detectamos faltantes y preparamos tu Hoja de Ruta.

PUEDES USAR INFORMACIÓN QUE YA TIENES

Escribe, habla, pega información o sube un PDF. La aplicación puede leer el texto de un PDF y utilizarlo para evitar que tengas que escribir nuevamente toda la información.

IMPORTANTE

Esta aplicación no es el Gobierno de México ni sustituye al Consulado. Los requisitos pueden cambiar. Siempre debes confirmar la información oficial correspondiente a tu Consulado.

¿QUÉ NECESITAS?

Elige el trámite que quieres preparar.

¿YA TIENES UN PDF?

Puedes subirlo aquí. La aplicación leerá el texto que pueda extraer y después podrás revisarlo.

TUS DATOS

Primero necesitamos identificarte para preparar correctamente la información.

REVISA ESTOS DATOS

Nombre, fecha de nacimiento, edad, dirección, estado, código postal y teléfono.
